# Метрики якості

Для демонстрації якості проєкту використовуються:

- наявність тестів Jest + Supertest;
- покриття коду через `jest --coverage`;
- наявність Dockerfile і docker-compose.yml;
- наявність CI pipeline через GitHub Actions;
- наявність Swagger / OpenAPI документації;
- наявність CHANGELOG.md та README.md.
