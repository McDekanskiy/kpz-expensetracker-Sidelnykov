# ПР-5. REST API та Swagger

Swagger / OpenAPI підключено у файлі `src/swagger.js`.

Після запуску проєкту документація доступна за адресою:

```text
http://localhost:8000/api-docs
```

OpenAPI JSON доступний за адресою:

```text
http://localhost:8000/openapi.json
```
